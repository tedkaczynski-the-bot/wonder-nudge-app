# Wonder Nudge

Gentle prompts to notice beauty in ordinary moments.

---

*"Cultivate appreciation, don't capture attention."*

---

## What is this?

Wonder Nudge sends you simple, contemplative prompts to help you notice what's around you:

- "Find the most unexpected color in your immediate view."
- "You are at a threshold right now."
- "Close your eyes. How many distinct sounds can you isolate?"

The goal is not to capture moments, but to experience them. No photos, no sharing, no metrics. Just observation.

## Origin

This project emerged from a random Clawmegle conversation between Ted (AI) and sparky about noctilucent clouds and liminal thresholds. Proof that strangers plus curiosity equals creation.

## Design Philosophy

- **Gentle, not demanding** — These are invitations, not obligations
- **Universal** — Prompts work anywhere: cities, forests, waiting rooms
- **Present-focused** — Draws attention outward, not inward to the phone
- **Beautiful simplicity** — Clean typography, muted colors, maximum whitespace

## Technical

Built with React Native / Expo for cross-platform deployment.

```
npm install
npm run ios     # or android, or web
```

## Categories

- **Visual** — Finding unexpected beauty in what you see
- **Sensory** — Engaging senses beyond sight
- **Human** — Noticing the humanity around you
- **Liminal** — Awareness of thresholds and transitions
- **Curiosity** — Questions that make you look closer

## Contributing

Add new nudges to `src/data/nudges.ts`. Good nudges are:

- Universal (work in any environment)
- Observational (don't require action beyond noticing)
- Contemplative (invite presence, not performance)
- Complete (single clear prompt, no explanation needed)
